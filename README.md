### Projetos em Destaque

* **[TaskFlow (Aplicação Fullstack)](https://github.com/keison13/taskflow-fullstack)** — Gerenciador multiusuário de tarefas e projetos com autenticação JWT, construído com Next.js, Node.js, Express e Prisma (PostgreSQL).
* **[BookStore API](https://github.com/keison13/BookStore-API)** — API RESTful construída em Spring Boot com geração automatizada de resumos de livros por IA via Groq API.
* **[Health Prompt (Senior Saúde)](https://github.com/senior-saude-movel/health-prompt)** — Sistema de IA conversacional e arquitetura cloud-native voltado para o ecossistema de tecnologia em saúde do NUTES, integrando modelos avançados, processamento de dados e fluxos automatizados.
* **[PainRAG](https://github.com/marcosBragaUni/painrag)** — Protótipo educacional em Streamlit para visualização de dados clínicos de pacientes (dor e sono), contando com chunking, embeddings, banco vetorial (ChromaDB), busca semântica validada e relatórios com RAG + LLM.
* **[LangChain Experiments](https://github.com/keison13/langchain-experiments)** — Aplicações práticas utilizando LangChain em Python, com foco em chats interativos com memória, manipulação de modelos de linguagem e integração com Streamlit.
